BudgetBasics test cases and submission results
==============================================

Test environment
----------------
Runtime: Bun package scripts; Vitest uses jsdom for component tests.
Commands: bun run test; bun run lint; bun run build
Use bun run test. The shorter bun test starts Bun's different built-in runner and does not apply this project's Vitest jsdom configuration.

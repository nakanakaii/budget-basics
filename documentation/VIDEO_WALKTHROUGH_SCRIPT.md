# BudgetBasics Video Walkthrough Script

Target length: 6 to 8 minutes. Recording and attaching the MP4 is a manual remaining deliverable.

## 0:00 to 0:35 Introduction

“BudgetBasics is a frontend-only learning website for students and first-time budgeters. It combines plain-language lessons with local interactive tools. No account, backend, database, or real financial information is required. I will demonstrate the navigation, learning modules, calculators, temporary expense planner, search, chatbot, and verification results.” Show the home page and main links.

## 0:35 to 1:10 Navigation

Identify the twelve primary destinations. Follow one link and point out its active state. Switch to a narrow viewport, open the mobile menu with the keyboard, choose a destination, and show that it closes. Mention Search, Sitemap, Privacy, and the reduced-motion-aware back-to-top control.

## 1:10 to 2:05 Learning modules

Open Budgeting Basics. Explain the six concepts with one student example. Answer a knowledge-check question incorrectly, read the explanation, retry, and show the correct response. Classify one need and one want. Open a money-mistake scenario and show consequence, action, and prevention.

## 2:05 to 2:35 Infographics

Filter the cards, deliberately create an empty state, and reset it. Explain that educational records are bundled locally.

## 2:35 to 3:15 Budget calculator

Enter 1000 SAR. Say: “The app suggests 500 for needs, 300 for wants, and 200 for savings.” Change the input and show the old result clears. Enter an invalid value and show validation. Explain that this is an educational guideline, not personalised advice.

## 3:15 to 3:55 Savings goals

Enter target 1200, current savings 200, and monthly contribution 300. Show 1000 remaining and four months. Demonstrate an overfunded goal capped at 100 percent and zero monthly contribution without a misleading date.

## 3:55 to 5:00 Expense planner

Enter 1200 in the separate Sample monthly income field. Add an expense dated 2026-09-01 in Transport with description “Monthly bus pass” and amount 200. Add a second expense dated 2026-09-02 in Food with description “Basic groceries” and amount 350. Show total expenses 550 and remaining 650. Edit an expense, delete one, demonstrate overspending, and reset. State that planner data is intentionally not persisted.

## 5:00 to 5:40 Search and chatbot

Search for “saving”, filter results, follow one, and reset. Ask “How much should I save?” then ask an unrelated question. Explain that answers are deterministic and local, not generative AI.

## 5:40 to 6:15 Support and privacy

Show About, Feedback, Contact, and Privacy. Submit valid sample feedback and an invalid email. Point out that the forms validate for demonstration but send nothing.

## 6:15 to 6:50 Verification and closing

Show `bun run test`, `bun run lint`, and `bun run build` results. Say: “The repository includes the report, reusable test data, recorded test cases, demo checklist, deployment guide, and Word installation guide. A Lighthouse audit is not claimed. This recording is the manual MP4 deliverable.” End on the home page and review the recording for readable text, audio, and accidental personal information.

# BudgetBasics Module Demo Checklist

Use sample values from `test-data.json`; do not enter real financial or contact information.

## Before recording

- [ ] Run `bun install`, `bun run test`, `bun run lint`, and `bun run build`.
- [ ] Run `bun run dev` and open the printed local URL.
- [ ] Set browser zoom to 100% and close unrelated tabs and notifications.
- [ ] Prepare a narrow responsive viewport.

## Application shell and learning

- [ ] Show the home page purpose and main calls to action.
- [ ] Open the responsive navigation by keyboard; follow a link and show its active state.
- [ ] Show Search, Sitemap, Privacy, and back-to-top behaviour.
- [ ] Explain the six concepts and one student example.
- [ ] Answer a knowledge-check question, show feedback, and retry.
- [ ] Classify a need and a want and read the reasoning.
- [ ] Open a money-mistake scenario; show consequence, action, and prevention.
- [ ] Filter infographics and reset an empty result.

## Calculators and planner

- [ ] Calculate a 1000 SAR budget and show 500 / 300 / 200.
- [ ] Change income and show that a stale result clears.
- [ ] Estimate a 1200 target from 200 current savings at 300 monthly.
- [ ] Demonstrate zero contribution and complete-goal cases.
- [ ] Add 1200 income, 200 transport, and 350 groceries.
- [ ] Confirm totals of 1200 income, 550 expenses, and 650 balance.
- [ ] Edit, delete, overspend, and reset; show validation for a bad value.

## Discovery, support, and closing

- [ ] Search for a saving resource and follow its route.
- [ ] Ask the chatbot a prepared and unsupported question.
- [ ] Show that feedback and contact forms validate but remain local demonstrations.
- [ ] Show terminal test, lint, and production-build results.
- [ ] State that the app is frontend-only and transmits no private data.
- [ ] Do not claim a Lighthouse score unless a separate audit is performed.
- [ ] Record, review, and attach the MP4 manually.
